## 과제 목표

`bohye/week0/README.md`의 자기소개 내용을 바탕으로 자기소개 이미지를 제작한다.

## 필수 요구사항

- 모든 작업은 `bohye/week1/` 아래에서 수행한다.
- README에 있는 정보를 모두 포함하며, README와 다른 내용을 넣지 않는다.
- 어떤 AI와 스킬을 어느 부분에 왜 사용했는지 PR 본문에 설명한다.
- 완성 이미지의 내용이 README와 다른 부분이 없는지 검증한다.
- 완성 이미지를 `bohye/week1/profile.png`로 커밋하고 PR 본문에도 포함한다.
- AI에 제출한 프롬프트와 AI 응답을 생략하지 않고 마크다운 문서로 제출한다.
- Codex 대화 기록은 `bohye/week1/prompt.md`에 정리한다.

## 제출 및 리뷰

- 개별 브랜치에 커밋한 뒤 `main` 브랜치 대상 PR을 제출한다.
- PR에는 작업 내용을 설명하고 리뷰어를 지정한다.
- 필수 리뷰어는 `@juwonlee-dev`, `@juhwanHeo`이며, 추가 리뷰어를 1명 이상 지정한다.
- 과제를 완성하지 못했더라도 마감 기한까지 PR을 제출하고, 미완성 부분은 마감 후 7일 이내 완료한다.

## 검증 기준

- 이미지의 이름, 생년월일, 성별, 역할, MBTI가 README와 일치한다.
- 관심 기술과 각 설명이 README와 일치한다.
- 스터디 참여 목적과 세부 학습 목표가 README와 일치한다.
- AI 활용 내용과 대화 기록 안내가 README와 일치한다.
- 최종 다짐 문구가 README와 일치한다.
- 텍스트가 잘리거나 겹치지 않고 한글이 정상적으로 표시된다.
