# Codex 작업 및 기록 지침

작업 디렉터리는 `juwonlee/week0`으로 한정한다. 작업 디렉터리가 변경되기 전까지 다음을 지킨다.

1. 모든 파일 작업과 명령은 이 디렉터리 내부에서만 수행한다.
2. 사용자가 입력한 각 프롬프트, Codex의 응답, 그리고 작업 중 콘솔에 출력된 텍스트를 `codex-prompt.txt`에 누적 기록한다.
3. 각 사용자 프롬프트는 `===== USER PROMPT =====` 구분자로 명확히 구분한다.
4. 작업 콘솔 출력은 `===== CONSOLE OUTPUT =====`, Codex 응답은 `===== CODEX RESPONSE =====` 구분자로 기록한다.
5. 새 기록은 기존 내용을 지우지 않고 파일 끝에 추가한다.
6. 파일 생성·수정·삭제·이동 및 Git 관련 작업은 착수 전에 Plan 모드로 작업 계획을 작성해 사용자 확인을 받은 뒤 수행한다. 사용자 승인이 있기 전에는 해당 변경 작업을 하지 않는다.
7. 파일 및 Git 작업을 제외한 작업은 실행 계획을 세운 뒤 사용자 승인 없이 즉시 수행하고 결과를 보고한다. 탐색·검색·조사 등 조회성 작업은 계획 승인 없이 수행할 수 있다.
8. 이 디렉터리에서 수행한 각 작업이 완료되면 Conventional Commits 형식의 메시지로, 이 디렉터리 안의 변경 사항만 스스로 Git 커밋한다.
9. 사용자가 PR 작성을 요청하면 Markdown 형식의 PR 초안을 작성한다. 관련 이슈가 있으면 링크하고, 변경 내용·검증 결과를 읽기 좋게 정리한다. 초안을 사용자에게 확인받은 뒤에만 GitHub에 PR을 등록한다.
10. GitHub에 PR을 등록하기 직전에는 해당 시점까지의 프롬프트·응답·작업 콘솔 기록을 `codex-prompt.txt`에 먼저 반영하고, 이 파일을 포함해 커밋한 뒤 원격 저장소에 푸시한다. 그 후에만 PR을 등록한다.
