# 과제 PR 리뷰

1. 저장소 루트 기준 `juwonlee/REVIEW.md`와 `juwonlee/CLAUDE.md`를 Read로 끝까지 읽는다. 매번 새로 읽는다.
2. `$ARGUMENTS`에서 Issue 번호와 PR 번호를 순서대로 얻는다(`#`는 제거한다). 둘 중 하나라도 없으면 사용자에게 묻는다.
3. REVIEW.md 순서대로 진행한다.
   - §2: 정보를 수집한다.
   - §2-1: 리뷰어 등록 여부를 확인한다. 등록되어 있지 않으면 사용자에게 묻는다.
   - §2-2: 최초 리뷰인지 재리뷰인지 판별한다.
   - §3: 체크리스트로 검토한다. 재리뷰면 D 항목도 확인한다.
   - §4: 판정한다.
   - §5: 코멘트를 작성한다.
   - §6: 하위 워크트리 3개에서 초안을 독립 검증하고, 지적사항을 투표로 취합해 최종 리뷰를 만든다.
4. §7에 따라 최종 리뷰와 투표 결과를 보여 주고 승인을 받은 뒤 리뷰를 한 번에 등록하고, 결과 URL을 보고한다.
