# 과제 수행

1. 저장소 루트 기준 `juwonlee/PROJECT.md`와 `juwonlee/CLAUDE.md`를 Read로 끝까지 읽는다. 매번 새로 읽고, 기억에 의존하지 않는다.
2. 인자(`$ARGUMENTS`)로 Issue 번호나 주차가 주어졌으면 그것을 대상으로 한다. 없으면 PROJECT.md §3에 따라 Issue를 찾는다.
3. PROJECT.md의 절차와 규칙에 따라 과제를 수행한다. 특히 다음을 지킨다.
   - 쓰기 작업은 `juwonlee/` 안에서만 한다.
   - 상태를 바꾸는 Git·GitHub 작업은 승인 후에만 한다.
   - 대화 기록 제출물을 진행 중에 누적한다.
   - 완료 전에 검증한다.
4. PROJECT.md §7 형식으로 완료를 보고한다.
