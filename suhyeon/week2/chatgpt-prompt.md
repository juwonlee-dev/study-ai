## 작업 요구사항
1. **원본 이미지 분석**
   - `study-ai/suhyeon/week1/profile.png` 파일을 직접 확인하고 디자인을 분석해줘.
   - 이미지에 포함된 모든 텍스트와 정보는 누락 없이 반영해줘.
   - 레이아웃, 색상, 폰트 크기, 여백, 정렬, 테두리 등 시각적 요소를 최대한 원본과 동일하게 구현해줘.

2. **HTML/CSS 구현**
   - 원본 이미지를 `<img>` 태그나 `background-image`로 그대로 출력하지 말고 HTML 요소와 CSS를 사용해 화면을 재현해줘.
   - 텍스트는 이미지가 아닌 실제 HTML 텍스트로 작성해줘.
   - CSS Flexbox 또는 Grid를 활용하여 레이아웃을 구성해줘.
   - 불필요한 라이브러리나 프레임워크는 추가하지 마.

3. **파일 생성**
   - 결과물은 `study-ai/suhyeon/week2/` 디렉터리에 생성해줘.
   - HTML 파일명: `index.html`
   - CSS 파일명: `style.css`
   - 기존 `week1` 디렉터리와 파일은 수정하지 마.

4. **검증**
   - 구현된 화면을 원본 이미지와 비교하여 디자인 차이를 점검해줘.
   - 텍스트 누락, 레이아웃 불일치, 스타일 오류가 있다면 수정해줘.
   - 브라우저에서 `index.html`을 열었을 때 정상적으로 표시되도록 해줘.

## 필수 요구사항

### 1. 원본 이미지 분석
- `suhyeon/week1/profile.png` 파일을 직접 확인하고 분석해줘.
- 이미지에 포함된 모든 텍스트와 자기소개 정보를 빠짐없이 반영해줘.

- 이미지에 없는 정보는 임의로 추가하지 마.

### 2. HTML/CSS 구현
- 원본 이미지를 `<img>` 태그나 `background-image`로 삽입하는 방식은 금지해.
- 이미지에 포함된 텍스트, 도형, 카드, 장식 요소 등을 실제 HTML 요소와 CSS로 구현해줘.
- CSS Flexbox, Grid 등을 활용하여 레이아웃을 구성해줘.

- 브라우저에서 `profile.html`을 열었을 때 정상적으로 표시되는지 확인해줘.
