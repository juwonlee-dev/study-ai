Issue에서 **“본인이 작성한 프롬프트와 AI 응답 결과 포함, 생략 없이 제출”**이라고 되어 있기 때문에 지금까지의 이미지 생성·수정·검증 대화를 최대한 그대로 넣는 게 중요해.

**3단계 — GitHub에 파일 커밋**

`week1/gunsang` 브랜치에 아래 구조로 생성:

```text
gunsang/
└── week1/
    ├── profile.png
    └── prompt.md
```

여기서 중요한 건 **`main`에 바로 넣는 게 아니라 `week1/gunsang` 브랜치에만 커밋하는 것**이야.

커밋 메시지는 예를 들면:

```text
feat: add week1 profile image and prompt log
```

정도로 하면 깔끔해.

**4단계 — 커밋 후 최종 검증**

PR 만들기 전에 한 번 더 확인한다.

- `profile.png` 파일이 정상적으로 열리는지
- README 자기소개 내용과 이미지 내용이 일치하는지
- `prompt.md`에 사용자 프롬프트와 AI 응답이 빠지지 않았는지
- 파일 경로가 정확히 `gunsang/week1/`인지
- `main` 대비 Week1 파일만 추가되었는지

특히 마지막 항목이 중요해. 지금은 `week1/gunsang`이 `main`과 **0 commit 차이**라 상태가 아주 깔끔해. 여기서 Week1 파일 2개만 추가하면 PR diff도 깔끔하게 나온다.

**5단계 — PR 생성**

PR은:

```text
week1/gunsang
↓
main
```

으로 생성한다.

제목은 기존 Week0 스타일에 맞춰서:

```text
Week1/gunsang 과제 제출
```

정도가 적당해.

PR 본문은 이런 형태로 작성하면 과제 요구사항을 거의 그대로 충족해.

```md

3. 생성 이미지와 README 내용 비교 및 검증
4. ChatGPT 이미지 생성 기능을 활용한 이미지 제작 및 수정
5. 전체 프롬프트 및 AI 응답 내용을 prompt.md로 정리

### ChatGPT

- AI 사용 내역 영역 제거
- 카드 기울기와 내부 콘텐츠의 원근 및 기울기 통일
- 최종 자기소개 정보 검증

## README 내용 검증 결과

- 성별
```
