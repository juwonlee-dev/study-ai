# 이건상

- **생년월일**: 2000.10.22
- **성별**: 남
- **직무**: Vue.js와 Spring Boot를 활용하는 풀스택 웹 개발자
- **주요 경험**: 공공기업 프로젝트에서 소상공인을 위한 지원사업 관련 메뉴 개발

- **개발 목표**: 사용자와 운영 환경을 함께 고려하여 안정적이고 효율적인 서비스를 만드는 개발자
